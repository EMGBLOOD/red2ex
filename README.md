# reDriver 2: Extended

Project page and bug tracker for **reDriver 2: Extended**, a community extension of the Driver 2 engine rebuild (REDRIVER2).

- Project page: https://emgblood.github.io/red2ex/
- Bug reports and feature requests: use the Issues tab (the forms ask for your log).

The source code is **not published yet**. The first public release (0.4.0) will bring it, with the licence and credits. This repository only holds the project page for now.
