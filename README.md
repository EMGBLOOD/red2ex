# reDriver Extended

Project page and bug tracker for **reDriver Extended**: **reDriver 2: Extended**, a community extension of the Driver 2 engine rebuild (REDRIVER2), and **reDriver: Extended**, Driver 1 on the same engine.

- Project page: https://emgblood.github.io/red2ex/
- Downloads: see the Releases tab.
- Bug reports, crashes, controller problems, mods, translations and feature requests: use the Issues tab (the forms ask for your log).

This repository only holds the project page and the issue forms.
