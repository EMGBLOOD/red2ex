Project Hub: Overview, Changelog, Bug Reports

reDriver 2: Extended is a fan made, free mod of Driver 2, set in the late 70s and early 80s. It adds split screen for up to 8 players, a level editor, many more cars, better graphics and lots of options. You need your own copy of the original game; nothing from the game discs is here or in the mod.

        How to report a bug

        1. Play once more and note what you did. A report that says what you clicked, in which city and with which car is fixed much faster.
        2. Find the log files. They are in the logs folder next to the game: logs\log.txt always, and logs\crash.txt when the game crashed. Copy them somewhere before you start the game again, because every start overwrites log.txt.
        3. Open the bug form with the button below, fill in the game version (shown at the top of this page and in the main menu) and attach both files. Reports without log.txt cannot be investigated and are closed.

        Privacy

        This page is static: it has no cookies, no analytics, no fonts or scripts from other sites and it never sends anything you do here anywhere. Its only network request is, when switched on, a read of the public issue list from GitHub, and the request goes from your browser to GitHub (their privacy policy applies); the answer is kept in your browser for 10 minutes. The Report button only opens a page of GitHub with an empty form. Logs can contain your Windows folder names, so look at them before you attach them.
